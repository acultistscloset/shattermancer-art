# Generation Record

Built-in image generation produced each painted source independently, using the approved Gate 2 status rails as the material authority: blackened iron, worn near-black leather, muted oxidized brass, restrained oxblood wax, and quiet cool brown-grey parchment.

Source prompts required transparent backgrounds, no variable text or numbers, no element marks, no mana fills, no vials, and no spell illustrations. The book prompt required exact fixed inscriptions—`GRIM`, `OIRE`, `INCANTATION`, and `INSIGHT`—measured against the physical page widths. The seal prompt required a genuinely recessed staff-casting signet. The CAST prompt required small centered lettering with clear edge breathing room.

Two source corrections were made before delivery: the book headings were moved clear of the parchment-strip band, and the rune control's accidental blue mana fill was removed. Deterministic alpha cleanup removed generated checkerboard pixels without repainting the subjects.
