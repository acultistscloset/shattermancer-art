# Status-asset generation prompts

Built-in image generation was used to create the three painterly raster sources. The final production files were alpha-validated, tightly normalized, and reduced to their declared implementation canvases.

## Health-bar frame

Create a long, very thin empty recessed health-bar trough with a narrow worn blackened-iron and oxidized-antique-brass rim. Match the restrained hand-painted dark-fantasy status-frame materials. Transparent background; no fill, text, number, symbol, shield, glow, or matte.

## Health-bar fill

Create a long, thin continuous oxblood-red painted health fill designed to sit inside the empty frame and be width-clipped. Subtle broken brush texture, modest upper-edge light, deep lower edge. Transparent background; no frame, border, text, icon, flame, neon glow, or matte.

## Shield badge

Create a compact forward-facing traditional shield badge with a thin oxidized-brass edge and near-black worn-iron interior, leaving a clear central field for a runtime number. Transparent background; no number, text, heraldry, sword, glow, medallion, or matte.
