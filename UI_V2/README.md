# Shattermancer UI v2

**Project-control package:** Gate 000\
**Purpose:** Establish the permanent governance, authority, checkpoint,
and phase-gate system before UI v2 design production begins.

## Core rule

`Shattermancer-art/UI_V2/` is the authoritative design record for UI v2.
Conversation history and model memory are working context only. If they
conflict with an approved repository document, the approved repository
document wins.

The production `Shattermancer` repository remains authoritative for
current game logic and current production behavior.

## Gate 000 use

This package is a **review candidate**, not yet locked. After explicit
owner approval:

1.  place `UI_V2/` at the top level of `Shattermancer-art`;
2.  commit the approved contents;
3.  create checkpoint/tag `ui-v2-000-project-governance`;
4.  change `00_MASTER_STATUS.md` to `PHASE 0 — IN PROGRESS`;
5.  begin Phase 0: Complete Game Inventory.

Do not begin production art, v2 visual implementation, or screen
redesign before Gate 000 approval.
