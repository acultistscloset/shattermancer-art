# Phase 08 --- Art Production

**Status:** NOT STARTED

## Purpose

Produce production art only from approved manifest entries and geometry.

## Required work

Work in controlled batches; require exact dimensions/transparency;
preserve native pixel authorship; record hashes/provenance; use previews
as review evidence, not geometry authority.

## Prohibited work

Unmanifested production assets; casual regeneration of unchanged
approved assets; geometry changes hidden inside art.

## Required deliverables

Versioned art packages and gate reports tied to manifest IDs.

## Completion gate

Each art batch passes its own explicit approval gate.
