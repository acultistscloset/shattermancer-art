# Phase 06 --- Stress Testing

**Status:** NOT STARTED

## Purpose

Attempt to break approved geometry before art production.

## Required work

Test relevant extremes: longest labels/names, minimum/maximum values,
empty/full lists, locked/disabled/selected states, maximum
history/content, alternate paths/data, supported viewports and unusual
but valid runtime states.

## Prohibited work

Production art used as a workaround for failed geometry.

## Required deliverables

Per-screen stress-test matrix and resolved failure record.

## Completion gate

Blocking overflow/collision/state failures are zero or formally resolved
through approved specification changes.
