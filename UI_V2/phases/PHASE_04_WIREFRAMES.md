# Phase 04 --- Art-Free Wireframes

**Status:** NOT STARTED

## Purpose

Prove information layout and interaction without production art.

## Required work

Create clean v2 wireframes using debug/simple geometry. Validate
hierarchy, tap targets, text fit, scrolling, safe areas, dynamic
content, representative phone heights/aspects and state transitions.

## Prohibited work

Using production art to conceal unresolved geometry.

## Required deliverables

Approved wireframes for every required screen/state family.

## Completion gate

Wireframes are visually approved as layouts and functionally complete
enough for geometry contracts.
