# Phase 02 --- Global Design System

**Status:** NOT STARTED

## Purpose

Turn the locked visual identity into reusable measurable UI rules.

## Required work

Define logical pixel density/scaling, viewport/safe-area strategy,
spacing grid, typography, numerals, palette, element colors,
health/shield/mana/currency conventions, control states,
borders/highlights/shadows, icon-size families, interaction feedback,
animation principles and accessibility/readability constraints.

## Prohibited work

Screen-specific production art or implementation.

## Required deliverables

A global design-system specification with measurable tokens/rules.

## Completion gate

Common components can be designed consistently without inventing new
global rules screen-by-screen.
