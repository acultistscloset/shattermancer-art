# Phase 00 --- Complete Game Inventory

**Status:** NOT STARTED

## Purpose

Establish a complete evidence-based inventory of the existing game
before redesign decisions begin.

## Required work

Inventory every screen/sub-screen, overlay/modal, navigation route,
persistent region, control/tap target, runtime text, dynamic number,
state/variant, empty/disabled/locked/selected/error state, scroll
behavior, transition, UI-relevant animation, current asset dependency,
and relevant game-state/data dependency.

Claude may inspect `Shattermancer` using a strict schema supplied by the
design process. Repository evidence must be distinguishable from
inference.

## Prohibited work

Redesigning screens; choosing final materials/ornament; production art;
v2 implementation; final geometry.

## Required deliverables

Definitive screen inventory; navigation/relationship map; per-screen
component/state inventory; existing asset-dependency inventory;
unresolved/unknown list.

## Completion gate

Owner/design review agrees no known game surface is omitted and blocking
unknowns are zero.
