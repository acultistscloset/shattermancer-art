# Phase 03 --- Screen Specifications

**Status:** NOT STARTED

## Purpose

Define what every screen must communicate and do before drawing final
layout.

## Required work

For every Phase-0 screen define purpose, information hierarchy,
controls, dynamic content, states, navigation, thematic metaphor where
applicable, reusable global components, screen-specific components and
acceptance requirements.

## Prohibited work

Production art; implementation; undocumented geometry decisions.

## Required deliverables

Approved functional/UX specification for every screen.

## Completion gate

Every known screen has no known missing functional or visual state
requirements.
