# Phase 05 --- Geometry Contracts

**Status:** NOT STARTED

## Purpose

Create one authoritative geometry source for every v2 screen/component.

## Required work

Define machine-readable regions, components, repeated children,
anchoring, spacing, bounds, safe areas and responsive rules.

## Prohibited work

Unexplained negative offsets; multiple competing geometry authorities;
corrective transform/scale layers; padding as undocumented positioning;
oversized clipped pseudo-element painters; accidental legacy geometry.

## Required deliverables

Machine-readable geometry contracts mapped to approved wireframes.

## Completion gate

Every wireframe maps to one explicit geometry authority suitable for
implementation and validation.
