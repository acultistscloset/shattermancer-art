# Phase 07 --- Complete Asset Manifest

**Status:** NOT STARTED

## Purpose

Identify every production-art requirement before commissioning
production UI art.

## Required work

For each asset define ID, screen/system, purpose, logical/source
dimensions, states, reuse, runtime layers, transparency, scaling, pixel
rules, geometry reference, dependencies, approval and
provenance/version.

## Prohibited work

Commissioning unmanifested production UI art.

## Required deliverables

Human-readable manifest; machine-readable manifest; completeness audit
against screen specs/geometry.

## Completion gate

No known UI art requirement is missing, including numerals, meters,
empty states, pressed/disabled states and shared chrome.
