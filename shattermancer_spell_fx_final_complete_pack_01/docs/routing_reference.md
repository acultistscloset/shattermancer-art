# Outcome Routing Reference

| Game result | Primary sheet | Element handling | Visual grammar |
|---|---|---|---|
| One or more Fractures | `fx_impact_<element>.png` | Select the corresponding elemental sheet | Central bite and loud elemental burst |
| Resonate only | `fx_resonate.png` | Runtime tint | Exactly five separated motes drift apart; no central bite |
| All Resist | `fx_fizzle.png` | Neutral, draining toward gray | Wet magical failure that loses cohesion and falls |
| Perfect incantation | `fx_shatter.png` | Neutral authored treatment | Plane compresses, cracks, and throws unmistakable shards |

`fx_shockwave.png` and `fx_hitflash.png` are optional shared overlays when the established combat presentation calls for them. They do not replace the primary outcome sheet.

There are six elemental treatments—`fire`, `water`, `nature`, `lightning`, `ice`, and `shadow`. The seven disciplines do not create separate casting variants.
