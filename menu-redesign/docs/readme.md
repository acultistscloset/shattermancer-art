# Shattermancer Main Menu and Disciplines Update

This update contains only revised files. The previously delivered full-screen study background is unchanged and is not included.

The static PNG assets are trimmed to their painted subjects. State overlays retain the shared canvas of the control or figure they modify. The two full-screen previews are rough placement references at 880 × 1912 pixels and are not measured layouts.

The Main Menu preview presents the wright as the dominant figure. Seven active discipline manifestations follow an irregular spiral with unequal spacing, depth, scale, and rotation. They are spell events rather than framed symbols.

The Disciplines preview presents seven selectors around the wright and an open Grimoire in the lower portion of the screen. The Pyromancer is shown selected; the remaining six selectors demonstrate the locked treatment.

All variable discipline names, descriptions, and progress counts remain unpainted in the separate assets. They appear only in the rough preview to communicate intent.
