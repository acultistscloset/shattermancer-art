# Placement Notes

Reference screen: 440 × 956 points in portrait. Keep critical lettering and controls below the top 6.2% safe band and above the bottom 3.6% safe band.

## Main Menu

- Place the Shattermancer logo across roughly 6%–24% of screen height.
- Let the wright dominate roughly 19%–72% of screen height and about 54% of screen width. Preserve the full hand-to-hand silhouette.
- Arrange the seven discipline manifestations along an irregular clockwise spiral from roughly 20%–69% of screen height. Vary their radius, scale, tilt, depth, and spacing. Do not distribute them as a grid or evenly spaced ring.
- Let some manifestations pass behind the wright and others pass in front. Keep the Pyromancer manifestation visually connected to the raised left hand.
- Place the three menu controls from roughly 73%–95% of screen height with narrow but visible vertical breathing room.
- When a saved run exists, use the Continue lettering in the first control. Otherwise use New Game. Start Anew is dimmed only when no saved run exists.

## Disciplines

- Place the back control and Disciplines heading within roughly 7%–15% of screen height.
- Let the wright occupy roughly 17%–64% of screen height. The full figure and both hands should remain legible.
- Arrange the seven selectors around the wright from roughly 16%–57% of screen height. Use unequal spacing and preserve a clear path around the head and hands.
- For an unlocked selector, layer the default frame and its discipline icon. For a selected selector, add the matching selected aura behind the frame and the matching light overlay directly over the wright.
- For a locked selector, add the locked overlay and lock medallion while keeping the underlying discipline recognizable.
- Place the open Grimoire and its cast shadow from roughly 63%–97% of screen height. Place the selected discipline icon in the socket near the upper-left page area.
- Reserve the upper page area for a variable discipline name and description. Place the two action controls in the lower half of the spread.

## Shared-state alignment

- Main Menu control overlays align exactly to the Main Menu control default canvas.
- Selector state overlays and selected auras align exactly to the selector default canvas.
- Wright light overlays align exactly to the neutral wright canvas.
- Grimoire action overlays align exactly to the Grimoire action default canvas.
- Page-turn front and reverse overlays share one canvas.
- The selected-page light aligns exactly to the open Grimoire spread.
